# Boddy Board

Доска целей для группы «Твой Бадди».

## Что внутри

- Вход участника по имени и паролю.
- Сохранение входа на устройстве до нажатия «Выйти из учётной записи».
- Общий дашборд участников, целей, сроков и прогресса.
- Администратор может удалять участников.
- Администратор может публиковать и удалять новость для участников.
- Участник видит новость один раз, после закрытия она считается прочитанной.

## Файлы

- `index.html` - разметка приложения.
- `styles.css` - дизайн.
- `app.js` - логика интерфейса.
- `api/state.js` - серверная функция для общей доски на Vercel.
- `assets/boddy-cover.png` - обложка.

## Как загрузить на GitHub

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы из этой папки.
3. При желании подключите репозиторий к Vercel.

## Важно

Сейчас общая доска хранится через JSONBlob. Для большой группы лучше потом перейти на Supabase, Firebase или Vercel KV.
